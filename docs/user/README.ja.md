## 主な機能

- Text、Graphic、Gallery表示に対応したゲーム一覧
- RetroArch、PicoArch、スタンドアロンエミュレータ
- DraStic、PPSSPP、PICO-8、Pyxel、OpenBOR、PortMaster
- ファイルマネージャー、音楽プレイヤー、サムネイル取得、ネットワーク転送
- ゲーム中も利用できる音量・明るさ操作と電源メニュー
- macOSとWindowsから読めるFAT32ユーザーパーティション

## 重要事項

plumOSはROMや利用者用ゲームBIOSを同梱しません。合法的に入手したデータを
用意してください。SDカードを抜く前には必ずPOWERメニューからシャットダウンし、
初回セットアップ、アップデート、ストレージ処理中には電源を切らないでください。

Pixel2はUSBポートが1つで、Wi-Fiを内蔵していません。対応Wi-Fiアダプターが
USBポートを使用するため、通常はWi-Fiと充電を同時に利用できません。ADBも
搭載していません。
