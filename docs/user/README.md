## Main features

- text, graphic, and gallery game-list views;
- RetroArch, PicoArch, and standalone emulators;
- DraStic, PPSSPP, PICO-8, Pyxel, OpenBOR, and PortMaster;
- file manager, music player, thumbnail scraping, and network transfers;
- global volume and brightness keys plus a power menu available in games;
- FAT32 user partition readable by macOS and Windows.

## Important

plumOS does not include ROMs or user-supplied game BIOS files. Prepare legally
obtained content yourself. Always shut down from the POWER menu before removing
the SD card. Do not remove power during first-boot setup, an update, or a
storage operation.

Pixel2 has one USB port and no built-in Wi-Fi. A supported Wi-Fi adapter uses
that port, so charging and Wi-Fi are not normally available at the same time.
ADB is not included.
