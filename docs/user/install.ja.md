# plumOS Pixel2のインストール

[English](install.md)

## 必要なもの

- GKD Pixel2本体
- 読み取り可能容量16 GB以上の信頼できるSDカード
- SDカードリーダー
- Pixel2用リリースイメージと公開SHA-256
- Raspberry Pi Imager、balenaEtcherなどのraw image書き込みツール

stockOSカードとは別のSDカードを使用してください。イメージを書き込むと選択した
カードの内容は消去されるため、開始前にデバイス名と容量を確認してください。

## 書き込みと初回起動

1. ダウンロードしたイメージのSHA-256が公開値と一致することを確認します。
2. 書き込みツールで展開済みのPixel2用`.img`を選択します。
3. 新しいSDカードを選び、イメージを書き込みます。
4. ツールの検証完了まで待ち、安全にカードを取り出します。
5. Pixel2へカードを挿し、電源を入れます。
6. 初回セットアップ中は電源を維持します。`PLUMOS_SYS`を拡張し、
   `PLUMOS_USER`を作成する途中で1回だけ自動再起動する場合があります。
7. 通常のフロントエンドが表示され、操作できる状態になれば完了です。

初回起動前に小さなboot volumeへROMをコピーしないでください。PCから読める
`PLUMOS_USER`は初回セットアップ完了後に作成されます。

## セットアップ後にコンテンツを追加する

1. `START -> POWER -> Shutdown`を実行し、画面が消えるまで待ちます。
2. SDカードを抜いてPCへ接続します。
3. `PLUMOS_USER`を開きます。
4. ゲームを`roms/`内の対応フォルダへ、必要なBIOSを`bios/`へコピーします。
5. カードを安全に取り出し、Pixel2へ戻して通常起動します。

フォルダ構成は[SDカードとフォルダ](storage.ja.md)を参照してください。
セーブや重要なコンテンツは、別のディスクにもバックアップしてください。
