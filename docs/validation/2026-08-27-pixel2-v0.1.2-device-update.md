# Pixel2 v0.1.2 device update validation

Date: 2026-08-27

Device: GKD Pixel2 at `192.168.10.107`

## Starting state

The device was running the PICO-8 acceptance build rather than the public
v0.1.1 Runtime:

```text
Runtime: 0.1.1-dev-083ab3f
System:  0.1.0
FE ready: yes
pending request: none
pending Runtime: none
last result: runtime_healthy
```

The public release package correctly requires source version `0.1.1`, so it
was not forced onto this development Runtime. The installed
`checksums.sha256` was captured read-only and used to build a device-specific,
signed transition to the exact formal v0.1.2 app-layer. The public release
package was not modified.

Pre-update Runtime verification read all 11,291 managed entries successfully:

```text
runtime_verify=result-ok
installed checksums SHA-256:
a46c5dd7711d004189ac50b109012e2a7fc80f0b51f225fa8ad5a0849aafe7ad
```

Host and device updater inspection both accepted the Ed25519 signature,
Pixel2 target, architecture, vendor Runtime, ABI, exact source version,
manifest, and payload. The package was copied under a hidden temporary name,
hashed on the device, atomically renamed into the update inbox, synced, and
hashed again before the request was committed.

ROMs, BIOS files, saves, states, Wi-Fi credentials, settings, proprietary
PICO-8 files, and PortMaster-installed content were outside the transaction.

## Acceptance boundary

This validates the formal v0.1.2 Runtime payload, transactional update,
post-boot health, complete managed-file readback, frontend restoration, and
Wi-Fi restoration on real Pixel2 hardware. The exact public update chain still
requires a device starting at public Runtime v0.1.1, and the newly generated SD
image was not separately fresh-card booted for this point release; its
first-boot geometry and provisioning paths remain covered by the release host
fixtures.

## Publication

The user explicitly accepted the device result and requested publication. Tag
`v0.1.2` points to the immutable release source recorded by the manifest:

```text
706b25bfbac348ca9d336b174bcf73e6df794571
```

GitHub Release `plumOS Pixel2 v0.1.2` was published with seven assets: the SD
image archive, exact source archive, signed Runtime update, update checksum
sidecar, release manifest, bilingual release notes, and aggregate checksums.
GitHub reported every asset as uploaded with matching SHA-256 metadata. The
repository verifier then downloaded all seven assets from the public release
URL, tested the 7z archive, streamed the uncompressed image, and matched its
size and SHA-256 against the signed provenance:

```text
release_redownload=result-ok assets=7
```
