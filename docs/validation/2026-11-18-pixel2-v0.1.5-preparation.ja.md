# Pixel2 v0.1.5配布物の準備

[English](2026-11-18-pixel2-v0.1.5-preparation.md)

新規SD image、対応source、公開v0.1.4用の署名Runtime updateを生成し、配布用updateを
実機へ適用して検証する。GitHub公開は今回の対象外。

v0.1.4以後の変更はhardware-key daemon、RetroArch patch 037/038、testsとdocs。
frontendとRetroArchは通常scriptで再buildし、その他はsource/recipe差分とchecksumを
確認した変更なしのv0.1.4 componentを再利用する。未再build componentの元のsource
manifestは維持する。既存scriptでRuntime/System/SD imageを生成し、strict gateと
連続2回のSD image SHA一致を要求する。

公開updateの基点として、v0.1.4 app layerを
`output/release-base/v0.1.4/plumos`へ保持する。checksum indexのSHA-256は
`abbf3236cba85b6e31d9aae8e2c5f1b57b0c0f091ebeddc5e350536db70efec1`。
stock boot/kernel/DTBと初回User partition生成を維持し、新規SDの実機bootは
今回依頼されたlive updateとは別のoperator確認項目とする。

実機ではlive patch差分が配布updateで収束するか確認し、設定・save・BIOS・ROM・
PortMasterをhash/countで記録。署名検証、一時名転送、実機hash、sync、atomic rename後の
再検証を経て、production updaterとsafe rebootを使う。更新後は0.1.5、source、
transaction healthy、pendingなし、全checksum、FE/Wi-Fi、mutable snapshot保持を確認する。
変更した電源メニュー復帰・整数スケールも再確認し、機械/capture確認とLCD目視は区別する。

最終artifact hashと実機結果は作業完了後に記録する。
