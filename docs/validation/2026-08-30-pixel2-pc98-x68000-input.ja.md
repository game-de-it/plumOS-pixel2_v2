# Pixel2 PC-98 / X68000入力検証

日付: 2026-08-30

## NP2kai

NP2kai上流の既定値`np2kai_joymode = "OFF"`では、RetroArchがPixel2の
RetroPad入力を受信してもkeyboard-driven PC-98 contentへ入力が渡らない。
MMFで実績のある方針に合わせ、factory core optionへ次を追加した。

```ini
np2kai_joymode = "Arrows 3button"
```

この設定では十字キーをPC-98 cursor key、A/B/X/Yを3-button keyboard
profile、SELECTをEscape、STARTをReturnへ変換する。config mergeはキーが
未設定の場合だけ既定値を追加し、ユーザーが選んだMouseなどの値は上書きしない。

実機ではFE経路からPC-98 contentが起動することをoperatorが確認した。機械検査は
起動、非黒画面、ALSA playback pointer進行に合格した。今回追加した物理入力mappingの
最終operator確認は継続する。

## PX68k

配布元が明確なフリーソフト「超連射68k」v1.10のXDFを検証用に使用した。

- Test content: `CH68_110.xdf`
- Source: `https://yosshin4004.github.io/x68k/crs68k/official/index.html`
- SHA-256: `6d8169ef89654fd7986b65eecfb5444dc496ac8e2f888b385a6b531ea3ef2146`
- Device path: `/mnt/plumos-user/roms/X68000/CH68_110.xdf`
- Core: `px68k_libretro.so`

XDFはユーザーパーティションへだけ配置し、repository、app-layer、release imageには
収録しない。FE経路でPX68kを起動し、機械検査で起動、非黒画面、ALSA playback
pointer進行に合格した。DRM captureではHuman68k起動後にゲームresourceを読み込む
画面を確認した。最後にoperatorがゲームの起動と物理操作を実機で確認し、合格とした。

機械検査だけでは音質、画面方向・比率・色、終了操作、save/loadを判定しない。
