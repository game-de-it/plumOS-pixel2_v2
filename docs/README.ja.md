# plumOS Pixel2 ドキュメント

文書は利用対象ごとに分けています。英語版は`.md`、日本語版は`.ja.md`です。

## ユーザー向け

[ユーザー向け取扱説明書](user/README.ja.md)には、インストール、操作、ストレージ、
ROM・BIOS、エミュレータ、セーブ、ネットワーク、アップデート、画像取得、
トラブル対応を記載します。ビルド手順や開発実験は含めません。

## 開発者向け

[開発者向けガイド](developer/README.ja.md)には、stock boot境界、パーティションと
更新構成、Dockerビルド、app-layer所有範囲、エミュレータ起動経路、
ハードウェアサービス、実機デプロイ規則、実機検証を収録します。

採用済み設計は`decisions/`、日付付きの成功・失敗・旧方式を含む開発根拠は
`validation/`に残します。これらは現在の利用者向け操作手順ではありません。
