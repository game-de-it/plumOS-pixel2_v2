# plumOS Pixel2 Documentation

The documentation is divided by audience. English files use `.md`; Japanese
counterparts use `.ja.md`.

## For users

The [User Guide](user/README.md) covers installation, controls, storage, ROMs,
BIOS files, emulators, saves, networking, updates, scraping, and
troubleshooting. It intentionally excludes build commands and experiment logs.

## For developers

The [Developer Guide](developer/README.md) covers the stock boot boundary,
partition and update model, Docker builds, app-layer ownership, emulator launch
paths, hardware services, live deployment rules, and physical validation.

Accepted designs remain under `decisions/`. Date-stamped files under
`validation/` preserve successes, failures, and superseded experiments and are
developer evidence rather than current user instructions.
